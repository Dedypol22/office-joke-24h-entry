A one-line office joke about the boss whose door is "always open" — open, that is, once you get past the keypad, the booking form and the three-day waiting list. The joke is: "My boss says his door is always open, but there's a keypad on it, a booking form, and a three-day waiting list." The setup promises access, and the punchline takes it all away on the last words, in one tight sentence anyone who has worked in an office will recognise.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if set) and prints it to stdout.
